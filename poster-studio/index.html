설정

Google Custom Search (기종 이미지 검색)
  1. console.cloud.google.com에서 프로젝트 생성 후 "Custom Search API"를 사용 설정하고 API 키를 발급합니다.
  2. programmablesearchengine.google.com에서 검색엔진을 새로 만듭니다.
  3. 검색엔진 설정에서 "이미지 검색"을 켜고, "전체 웹 검색"도 켭니다.
  4. 검색엔진 ID(cx) 값을 복사해 위 입력란에 붙여넣습니다.
GitHub (포스터 게시)
  1. GitHub → Settings → Developer settings → Fine-grained tokens 에서 새 토큰을 만듭니다.
  2. 대상 저장소를 지정하고, Repository permissions에서 "Contents"를 Read and write로 설정합니다.
  3. 발급된 토큰을 위 입력란에 붙여넣습니다. (토큰은 노출되지 않도록 주의하세요)
Solapi (문자 대량발송, 선택)

발신번호는 Solapi에 사전 등록(발신번호 사전등록제)이 필요합니다.
